Kuis Aplikasi EKG Aritmia

Soal pilihan A, B, atau C tentang semua fitur aplikasi ekg-aritmia.streamlit.app. Tulis nama, kerjakan, lalu lihat nilai dan penjelasannya. Kuis boleh diulang berkali-kali.

Nilai disimpan di browser perangkat ini. Untuk melaporkan nilai ke pengajar, kirim kode hasil yang muncul setelah kuis selesai. Kuis untuk pembelajaran, bukan alat diagnosis medis.
